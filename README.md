# CrystaNet

**Deep Learning for Plasma-Templated Crystallomics and Liver Fibrosis Detection**

## Overview

CrystaNet is a deep learning framework developed to analyze crystallization-derived image phenotypes for liver fibrosis detection. This repository contains the code for two classification tasks used in the study.

## Code Modules

### 1. Healthy Controls vs. Liver Fibrosis

Directory: `CrystaNet_GitHub_HC_vs_LF/`

This module contains the code for binary classification of healthy controls and participants with liver fibrosis, including internal five-fold cross-validation, final model training, and external validation.

### 2. F0 vs. F1 Liver Fibrosis

Directory: `CrystaNet-F1_GitHub_F0_F1/`

This module contains the code for distinguishing F0 from F1 liver fibrosis, including internal five-fold cross-validation and external validation.

## Software Environment

Each module includes its own README and environment configuration files documenting the software dependencies used in the corresponding analysis.

Please refer to the README within each module for setup instructions and usage details.

## Data Availability

Patient-level data and clinical images are not included in this repository. Access to any additional data is subject to applicable ethical approvals, consent requirements, and data-sharing restrictions.

## Code Availability

The source code is organized into task-specific modules to support transparency and reproducibility of the reported analyses.
